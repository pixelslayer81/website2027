STYLE SHIFT

Looks

What is it: Style Shift is a web app that re-renders any uploaded photograph in a chosen editorial "look" while guaranteeing the photo's content never changes. It takes the brand-aware generation workflow built in Claude and Runway and turns it into a designer-friendly tool, bringing all the AI and automation under the hood without requiring any coding.

Why we built it: Style Shift makes consistent, on-brand image transformation simple for everyone. It allows non-designers to easily restyle existing photography without having to understand prompts, design tools, or complex AI workflows. Visual styles are built into the tool, making results repeatable and consistent across images, campaigns, and channels. Users simply choose the look they want and Style Shift handles the complexity behind the scenes. The result is an easy-to-use system that helps teams create consistent imagery, reuse existing assets, and scale content without scaling complexity.

Looks

The Style Shift look lineup includes Candid, a signature documentary-inspired look with on-camera flash, natural film grain, and authentic 35mm photography aesthetics; Shadows, a dramatic look focused on bold lighting and contrast; and the Pantone Collection, a series of tone-on-tone color treatments available in Green, Pink, Blue, and future colorways. These looks transform clothing, props, and background surfaces into a unified color story while preserving key elements. Skin tones, hair, outdoor skies, laptops, and paper materials remain unchanged, backgrounds are recolored rather than replaced, and each image is limited to two solid accent colors for a clean, cohesive result. New Pantone colorways can be added quickly through a simple configuration update.

Audit

Quality assurance is built into every render. An automated audit compares each result to the original image and assigns a fidelity score based on how closely key elements match. The system flags issues such as changed objects, altered backgrounds, tinted skin, camera shifts, or color-rule violations. Recolor styles use specialized checks that allow intended color changes while detecting unwanted changes to content, identity, or composition.

How it works

  1. 1

    Upload

    Drop a photo onto the grid canvas — single or a batch run across many frames.

  2. 2

    Vision lock

    Claude reads the photo: a content-lock paragraph, the flash subject (auto or click-to-place), an auto-crop.

  3. 3

    Look resolve

    The look loads from a Brain YAML — palette, rules, finish. Pantone colorways merge the family hard rules. Code holds no aesthetics.

  4. 4

    Generate 4K

    Content-locked prompt to the Runway dev API (gemini_image3_pro). Developing frames stream to the canvas live.

  5. 5

    Post pass

    Deterministic finish from the YAML: tone-match, film grain, levels, blur. Pantone looks: zero post, clean editorial.

  6. 6

    Content audit

    Claude scores the render against the source, 0–100, with severity-coded violations. A critical fail is re-rolled — never delivered.

  7. 7

    Finish tools

    Live-preview adjustments — grain, levels, colour — plus social-format crop with the move / scale / rotate gizmo. All free.

  8. 8

    Export

    Download the PNG. Add to library — explicit click only. Send any saved image back to the canvas to re-crop.
